# Pedigree

A fully client-side family tree editor for the browser: create, edit, print and export a family
tree without a server, an account or any network traffic. All data stays on the device.

**Status: planning.** The technical plan (`docs/TECHNICAL_PLAN.md`) and the design plan
(`docs/DESIGN_PLAN.md`) are awaiting approval; no application code exists yet. Progress is
tracked in `PROGRESS.md`, decisions in `DECISIONS.md`.

Setup, usage and deployment instructions, the bundle budget figures and the large-format
printing advice will be added here in stage (a) and kept current in every later stage.
